# Publication checklist

1. Preserve the MIT license and its copyright notice when distributing copies or substantial portions of the software.
2. Publish only this project directory. Do not add local application data, backups, recordings, personal scripts, or generated build output.
3. Inspect all files, image metadata, commit history and any screenshots before sharing. Git records deleted files in history, so check before the first commit as well as later commits.
4. Use a repository name, public contact details and bundle identifier you are comfortable disclosing. Review your Git author name and email settings before creating commits.
5. Run the tests in `README.md`, build on the target Mac and verify the example and language selection.
6. If distributing binaries outside the App Store, decide how to sign, notarize and maintain them.

Review these checks before sharing future changes or distributing binaries.
